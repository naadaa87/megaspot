# 비공개 이용 의견 — 2026-11-17

고객 페이지: `/feedback/#feedback=<예약별 전용 토큰>`
관리자: `/admin/#feedback` (정산·사후관리 → 이용 의견)

이용 완료 예약만 링크 준비·설문 제출이 가능합니다. 관리자 화면에서 예약별 응답, 답변 요청 여부, 처리 상태(접수/확인 중/처리 완료), 내부 메모를 관리합니다. 링크가 없는 예약도 미응답 목록에 표시됩니다. 완료된 예약 목록의 이용 의견 버튼으로도 진입합니다.

링크는 32바이트 난수이며 서버에는 해시와 AES-GCM 암호문으로 보관합니다. 기존 DEPOSIT_ACCOUNT_KEY를 재사용하되 feedback-link 용도로 분리합니다. 링크는 발급 후 90일 유효하며 예약자·연락처·공간·날짜가 변경되거나 완료 상태가 해제되면 차단됩니다. 만료/예약자 변경 시 미응답 예약에서 새 링크를 준비할 수 있습니다. 예약당 제출은 1회이며 처리 메모는 고객에게 공개되지 않습니다. 답변 연락 요청은 자동 답변이 아닌 운영팀의 후속 연락을 위한 표시입니다.

`migrations/20261117_booking_feedback.sql`과 자동 초기화 스키마에 표를 추가합니다. 신규 표만 생성하며 기존 예약/정산/알림 설정은 변경하지 않습니다.

알림톡: **초안만 준비, 발송 연결 없음**. `config/feedback-alimtalk.pending.json`은 미등록 초안이며 발송 엔진에 추가하지 않았습니다. 완료 처리에 자동 발송/대기열 생성/템플릿 등록을 추가하지 않았습니다. 설문과 관리자 설문 API는 기존 백그라운드 발송 tick도 실행하지 않습니다. 추후 별도 지시에 따라 검수·발송 연결이 필요합니다.

검증: 메모리 SQLite/API 테스트, 기존 통합 안내·알림 회귀 테스트, Functions 빌드, 실제 고객/외부 발송이 차단된 로컬 가상 예약 화면에서 제출·처리 상태 저장 확인.
