# 보증금 환급 운영 (2026-11-03)

관리자: https://megaspot.kr/admin/#deposit-refunds

1. 예약 관리의 **보증금 환급** 또는 **보증금 환급 관리 → 전체 예약**에서 예약을 엽니다.
2. **고객 전용 링크 복사 / 고객 안내문 복사** 후 예약 담당자에게 직접 전달합니다. 복사만으로 문자·알림톡이 발송되지는 않습니다.
3. 고객은 은행·계좌번호 2회·예금주를 입력하고 동의 및 최종 확인 후 등록합니다.
4. 보증금 입금·이용 종료 후 시설·보증금액·차감액·고객 사전 안내·담당자를 확인하고 저장합니다.
5. **송금 처리 시작**으로 고객 수정과 중복 처리를 잠급니다. 은행에서 예금주·계좌·금액을 대조하고 직접 송금합니다.
6. 같은 관리자 로그인에서 실제 송금액을 재입력하고 성공 확인 후 **환급 완료 기록**을 누릅니다. 자동 이체는 하지 않습니다.
7. 로그인 만료·담당자 변경은 은행의 기존 송금 결과를 대조하고 **처리 이어받기**로 계좌 잠금을 유지한 채 진행합니다.
8. 결과 불확실 시 **보류**. 은행에서 미송금을 확인한 경우만 **대기로 복구**하고 시설을 재확인합니다.

## 운영 기준

- 실제 이용 종료일이 속한 주(월~일)의 다음 주 수요일 환급. 자정·익일 종료는 실제 종료일 기준입니다. 예: 일요일 밤 이용·월요일 아침 종료 → 그 다음 주 수요일.
- 보증금: 발급 확정서 deposit → 최근 연결 견적 deposit → 150,000원. 예약별 수정 가능.
- 차감 사유·사전 안내 확인 필수. 전액 차감은 송금 없이 0원 정산 확인 후 완료합니다.
- 기존 반환 체크 예약은 중복 처리하지 않습니다. 새 환급 완료는 기존 체크에 반영하고 다른 체크는 보존합니다. 문의에 여러 예약이 있으면 취소되지 않은 예약이 모두 환급된 뒤 반환 체크를 완료합니다.
- 고객은 처리 전까지 수정 가능. 변경 이력·버전을 표시하고, 처리 중·완료·보류에서는 계좌를 잠급니다.
- 전용 링크 재복사는 동일 링크. 폐기·재발급 시 기존 링크만 무효화하고 등록 계좌는 유지합니다.
- 1호는 기존 시설 안내서 내 폼, 2호는 1호 출입 안내를 잘못 전달하지 않도록 /deposit/의 별도 계좌 화면으로 연결합니다.

## 데이터·배포

- Production Pages Secret **DEPOSIT_ACCOUNT_KEY**: 난수 32바이트의 64자리 hex. 임의 교체·삭제 시 기존 계좌 복호화가 불가능합니다. Git·로그에 저장하거나 Preview에 복사하지 마세요. 관리자 비밀번호와 독립된 키입니다.
- 계좌·예금주·링크 토큰은 예약번호/용도 AAD로 AES-256-GCM 암호화. 토큰 SHA-256으로 조회. URL fragment 수신 후 제거, 해당 탭 sessionStorage에 최대 24시간 토큰만 보관합니다. 계좌는 브라우저 저장소에 보관하지 않습니다.
- 고객 응답은 끝 4자리. 전체 계좌는 인증된 관리자의 명시적 조회에만 반환하고 이력을 기록합니다. 로그에 계좌·예금주·토큰 원문을 기록하지 않습니다.
- 계좌 보유기간: 환급 완료 후 30일. 미완료 시 이용 종료일과 최종 등록일 중 늦은 날부터 90일. 만료 즉시 조회 차단, 정리 시 원문·마스크·링크 삭제. 환급액·처리 시각 등 거래 기록은 유지합니다.
- 매일 한국시간 03:20의 정리 Worker: deploy/deposit-retention/wrangler.jsonc. DB 바인딩·비밀값 없이 본사이트의 만료 전용 경로를 호출하며 공개 Worker URL은 비활성화합니다.
- cleanup 경로는 예약번호·시각 입력을 무시하고 서버에 저장된 기간이 지난 계좌만 삭제합니다. 고객 정보·삭제 건수는 반환하지 않습니다. 고객·관리자 요청에도 같은 정리를 수행합니다.
- 기존 관리자 인증·동일 출처 검사를 재사용. 고객 API는 안내서·본사이트 CORS만 허용하고 쿠키 미사용. 속도 제한·입력 검증·CAS·완료 일회성 조건 적용.
- 별도 계좌 유효성/예금주 실명조회·자동 송금·자동 발송은 하지 않습니다.
- schema.sql과 _schema.js는 추가 테이블/인덱스만 생성하며 기존 API 미들웨어가 첫 요청 시 적용합니다. 검토 SQL: migrations/20261103_deposit_refunds.sql.
- 본사이트는 기존 Git main 자동 배포. 안내서는 기존 megaspot-guide 프로젝트에 dist 배포. 본사이트와 안내서는 서로 다른 기존 Cloudflare 계정을 유지합니다.
