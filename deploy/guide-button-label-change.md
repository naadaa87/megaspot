**후속 요청으로 대체됨:** 고객이 버튼 3개 구성을 확정했습니다. `UN_3085`는 운영에 적용하지 않고, `deploy/guide-three-buttons.md`의 **UN_3115** 검수·전환 절차를 따릅니다.

- 요청 버튼: **시설·주차·케이터링 안내**. 구분점·공백 포함 13자이며 알리고 신규 템플릿 등록 API가 정상 접수했습니다.
- 기존 `UN_2584`는 승인 템플릿이므로 직접 수정하지 않았습니다. 같은 본문과 같은 모바일/PC URL을 사용하는 `메가스팟_예약고객_이용안내_버튼변경_v2` / **UN_3085**를 등록하고 검수 요청했습니다. 조회 상태는 **REQ(검수 중)**입니다.
- 등록 원문은 `config/reservation-guide-alimtalk.button-label-v2.template.json`에 보관합니다. 이전 등록 원문도 보존합니다.
- 서버는 시설 안내 방식에서 `UN_3085`를 명시적으로 선택했을 때 새 버튼 이름을 사용하도록 준비했습니다. `UN_2584`의 버튼·설정 지문과 통합 안내 `UN_2935`는 변경하지 않습니다. 이번 배포가 새 템플릿을 활성화하지는 않습니다.
- 승인 이후 릴레이의 기존 허용 코드 목록을 보존하며 `UN_3085`를 추가하고, 승인 본문·버튼·URL을 확인해야 합니다. 새 코드로 운영자 실제 시험 수신을 완료한 뒤에만 시설 안내 운영 설정을 전환합니다. 기존 시험 수신을 새 코드의 수신 증거로 재사용하지 않습니다.
- 기존 예약·발송 이력·중복 차단 목적은 유지합니다. 버튼 이름 변경만으로 기존 고객을 재발송 대상으로 만들거나 새 메시지를 소급 생성하지 않습니다.
