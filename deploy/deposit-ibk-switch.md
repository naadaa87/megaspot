# 보증금 입금 안내 기업은행 전환 (2026-11-16)

보증금 안내 계좌를 **기업은행 064-179058-04018 / 주식회사 지유공간개발**로 변경합니다. 보증금액·납부 기한·환급 기준은 유지합니다. 이번 계좌 변경은 보증금 안내에만 적용하며, 예약 포털의 별도 잔금 입금계좌는 변경하지 않습니다.

## 알리고 등록

- 기존 `UN_2759`: 승인된 하나은행 안내. 수정·삭제하지 않고 과거 발송 결과 확인용으로 보존합니다.
- 새 `UN_8363`: `메가스팟_보증금_입금안내_기업은행_v2`.
- 새 본문은 기존 본문에서 은행·계좌와 예금주 두 줄만 변경했습니다. 기본형(BA), 강조 없음(NONE), 버튼 없음입니다.
- 2026-11-16 공식 API로 등록·검수 요청을 완료했으며, 등록 직후 상태는 `REQ`/`R`입니다. 등록·검수 요청은 고객 메시지 발송이 아닙니다.

새 템플릿이 `APR` 승인이고 본문·버튼이 정확히 일치하며, 운영자의 새 템플릿 시험 알림톡이 실제 `delivered`로 확인되어야 입금 안내를 발송합니다. 기존 입금 안내의 시험 수신 기록을 새 계좌 안내의 시험으로 인정하지 않습니다. 검수·시험 완료 전에는 입금 안내 대기를 보존하고 발송하지 않습니다.

## 기존 환급 안내 보존

기존 설정의 `codes.payment=UN_2759`는 읽을 때 새 기본 코드 `UN_8363`으로 해석하며, 운영 DB 설정 자체를 다시 저장하지 않습니다. 일반 설정 저장은 기존 대기 발송을 취소하는 동작이 있으므로 계좌 전환을 위해 임의로 저장하지 않습니다.

`_deposit_template_legacy.js`는 과거 `UN_2759` 본문·이름·버튼의 **불변 지문 입력값**입니다. 이 파일에 남은 하나은행·블랭크 문구는 고객 신규 발송용이 아닙니다. 일괄 문자열 치환으로 바꾸면 과거 검증 기록을 보존할 수 없습니다.

기존 지문을 현재 발신 설정과 대조해, 내용과 코드가 그대로인 환급 계좌 등록·환급 완료 안내의 시험 수신 기록만 유지합니다. 발신 프로필·번호·서명/암호화 키 또는 해당 안내 본문·코드가 달라지면 이전 검증을 인정하지 않습니다. 검증되지 않은 입금 안내 여러 건이 대기해도 다른 두 종류가 처리 순서에서 막히지 않도록 종류를 먼저 필터링합니다.

과거 입금 안내의 접수·결과 불명 이력은 원래 `UN_2759` 코드·발신 프로필·수신자 해시로 결과만 조회하며 다시 발송하지 않습니다. 이미 보낸 메시지의 본문과 거래 이력은 소급 변경하지 않습니다.

## 릴레이와 고객 화면

기존 고정 IP 릴레이의 허용 목록과 SMS 대체 발송 대상에 새 코드만 추가합니다. 실제 서버에는 저장소에 없는 다른 코드도 있으므로 소스를 통째로 덮어쓰지 않습니다. 키·IP·타이머·발송 원장은 유지합니다.

예약 조회의 `deposit.bank`와 `/arrival/space1/`의 보증금 표시·계좌 복사 값도 같은 기업은행 계좌를 사용합니다. 별도 안내 주소 `megaspot-guide.pages.dev`는 현재 메인 사이트의 `/arrival/space1/`로 연결되므로, 예전 `dist/`를 새로 배포해 연결을 덮어쓰지 않습니다.

## 운영 확인

기존 고정 IP 서버의 `deposit-tick.mjs --status`는 서명된 읽기 전용 조회입니다. `codes`, `settings_match`, `tested`, `ready`를 확인할 수 있고 키·해시·고객 기록을 반환하지 않습니다. `ready`는 설정·시험 수신 준비 여부이며 공급자 승인 상태는 알리고 템플릿 조회로 별도 확인합니다.

새 템플릿 승인 후 관리자 **보증금 알림톡 → 운영자 시험 수신**에서 운영자가 본인 번호로 시험합니다. 이 단계는 실제 메시지와 발송 요금이 발생하므로 에이전트가 요청 없이 실행하지 않습니다. 새 시험이 도착하면 기존 자동 처리에서 새 계좌 안내를 사용합니다. 기한이 지난 대기는 기존 정책을 따르며 과거 예약을 소급 일괄 발송하지 않습니다.
