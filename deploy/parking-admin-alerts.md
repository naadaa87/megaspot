# 주차권 관리자 결제 알림

관리자: https://megaspot.kr/admin/#parking

페이앱의 서명 검증된 최초 결제 완료 상태 전환만 `parking_admin_sms_paid` 트리거로 관리자 번호마다 한 번 기록합니다. 테스트 주문, 다른 상품 주문, 판매 설정 전의 과거 결제는 발송하지 않습니다. 고객 알림톡의 승인·운영 발송 설정과 별도로 동작합니다.

관리자 → 주차권 관리 → 관리자 결제 문자 알림에서 번호와 발송 상태·내역을 확인합니다. 서버 `ALIGO_PARKING_ADMIN_RECEIVERS`에 승인된 번호만 수신 설정에 저장할 수 있습니다. 번호를 저장한 뒤 각 번호의 시험 LMS 도착 성공을 확인해야 자동 발송을 켤 수 있습니다. 기존 알리고 발신번호·API 키를 재사용하며, 키는 고정 IP 서버에만 보관합니다.

페이앱 결제 통보 API 응답 후 Pages `waitUntil`에서 발송하므로 관리자 화면을 열어 둘 필요가 없습니다. 대기 발송은 다음 API 요청에서도 확인합니다. 관리자 화면이 열려 있으면 10초마다 새 결제 알림을 확인합니다. API 수신과 최종 문자 도착 성공은 별도 상태로 표시합니다. 통신 결과 불명은 자동 재발송하지 않아 중복 발송을 방지합니다.

문자에는 차량번호·이용일·주차권·금액·주문번호·관리자 화면 주소와 '아마노 등록 전' 안내를 담습니다. 고객 연락처, 구매 내역 조회 비밀 키는 문자에 넣지 않습니다. 아마노 결제·할인 등록 자동화는 포함하지 않으며, 운영자가 실제 입차와 차량번호를 확인해 등록합니다.

주요 파일: `functions/api/_parking_admin_alerts.js`, `assets/js/pages/admin-parking-alerts.js`, `migrations/20261104_parking_admin_alerts.sql`, `deploy/aligo-relay/server.mjs`.

검증: 관리자 인증·동일 출처 제한, 수신 허용 번호·시험 도착 후 활성화, 새 실제 결제만 번호별 1회 기록, 동시 처리 중복 방지, 응답 불명 재발송 차단, 환불 전송 취소, 미확인 알림 읽음 상태 보존 및 기존 페이앱/주차 등록 테스트.
