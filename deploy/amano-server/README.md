# 아마노 서버 자동 처리 전환

## 현재 운영 상태 · 2026-11-04

기존 고정 IP 서버에 별도 `megaspot-amano.service`를 설치했습니다. 로컬 포트 8790과 HMAC으로 보호된 HTTPS `/megaspot/amano` 경로가 정상입니다. 기존 알리고·Caddy·commerce 서비스는 유지합니다. Cloudflare 관리자에서 연결 상태 조회가 성공하고, 같은 서버에서 서명된 메가스팟 처리 대상 조회가 HTTP 200으로 확인됐습니다. 확인 시 처리 대상은 0건입니다.

**서버 자동 등록 ON, 정기 타이머 enabled/active입니다.** 사용자 계정 연결 후 정상 로그인과 전체 차량번호 조회를 검증했습니다. 이미 완료된 입차ID 8070의 무료 1시간 1건·당일권 1건 및 잔액 489,000원을 서버 어댑터에서 읽기 전용으로 확인했습니다. 승인된 할인 코드·가격·시간도 모두 일치합니다. 추가 등록이나 추가 차감은 하지 않았습니다.

`megaspot-amano-tick.timer`는 한국시간 평일 10–18시 매 5분에 실행합니다. 공휴일·운영시간 밖은 사이트 API에서 큐와 등록을 차단합니다. 활성화 시점은 운영시간 이후여서 수동 검증 실행은 정상 종료하되 처리 0건/운영시간 외 대기로 기록됐습니다. 다음 정기 실행은 2026-11-05 10:00 KST입니다. 이 채팅의 기존 컴퓨터용 반복 작업은 PAUSED로 전환했습니다. 서버와 타이머는 재부팅 후에도 자동 시작합니다.

## 사용자 계정 연결

메가스팟 관리자 → 주차권 관리 → **아마노 서버 자동 처리 연결**에서 사용자가 직접 아이디·비밀번호를 입력하고 기존 서버 암호화 보관에 동의한 뒤 연결합니다. 비밀번호는 브라우저에서 SHA-256 변환 후 계정 정보와 함께 서버의 RSA-OAEP 키로 암호화합니다. Cloudflare는 암호문만 중계하고 서버는 정상 로그인 확인 후 AES-256-GCM으로 보관합니다. 세션·Chrome 쿠키를 복사하지 않습니다. 추가 인증·약관 동의가 나오면 우회하지 않습니다.

서버 상태 디렉터리는 `/var/lib/megaspot-amano`(0700), 파일은 0600, 실행 사용자는 기존 전용 사용자 `megaspot-aligo`입니다. 암호화 저장 키는 기존 root 환경의 연결 키에서 별도 문맥으로 파생하며 값은 출력하거나 저장소에 넣지 않습니다.

## 서버와 사이트의 경계

사이트의 `/api/parking/automation/server`는 기존 연결 키의 HMAC 서명·1분 유효시간을 검증합니다. 서버에는 당일 정상 실결제·미등록 주차권만 노출하며 고객 연락처와 구매 내역 비밀 키를 전달하지 않습니다. `claim`은 당일 입차와 무료 사용 이력 확인이 필요하고, `complete`는 무료 우선 확인·실제 등록 확인·정확한 승인 원가가 필요합니다. 익일 연속 주차·환불·취소 검토·확인 필요 건은 자동 처리하지 않습니다.

무료 1시간은 시간권·일일권 모두 필수 우선 적용하며 같은 입차ID에서는 한 번만 사용합니다. 시간권 기본 구성은 무료1+유료0/1/2, 일일권은 무료1+당일권입니다. 이미 무료 사용이 확인된 동일 입차 추가 구매만 무료 중복 없이 유료 전체 시간을 사용합니다. 원가 상한은 시간권 3,000/6,000/9,000원, 일일권 20,000원이며 추가 충전은 하지 않습니다.

## 확인한 전환 절차

1. 서버에서 사용자 계정으로 정상 로그인하고 해당 현장의 입차·전체 차량번호·할인내역·잔액·등록 원가를 검증합니다.
2. 아마노 정상 폼의 조회·할인내역·등록 요청 형식과 성공 응답을 확인해 어댑터를 구현했습니다. 실제 완료된 건의 조회와 모의 등록·중복 방지·결과 불명 보류를 검증했습니다.
3. 서버 코드·systemd 일정과 수동 실행 정상 종료를 검증한 뒤 한국시간 평일 10–18시 5분 간격 timer를 켰습니다. 공휴일은 사이트 API에서도 제외합니다.
4. 서버 처리 상태와 관리자 표시를 확인하고 이 채팅의 기존 컴퓨터용 자동 작업을 일시정지했습니다.

관련 검증: `node --test tests/amano-server.test.mjs tests/amano-api.test.mjs tests/parking.test.mjs`.

## 운영 점검과 중지

관리자 → 주차권 관리 → **아마노 서버 자동 처리 연결**에서 켜짐·중지와 최근 처리 결과를 확인합니다. 중지는 새 등록 요청 전에 다시 검사되며 진행 결과가 불명확한 건은 자동 재발송하지 않습니다. 처리 중 프로세스가 중단돼도 요청 직전 영구 기록을 남겨 다음 실행에서 확인 필요로 보냅니다. 실제 할인내역의 새 기록·주문번호 메모·잔액 차감이 모두 맞아야 사이트에 적용 완료를 기록합니다.

서버: `systemctl status megaspot-amano megaspot-amano-tick.timer`, 실행 결과: `systemctl status megaspot-amano-tick.service`. 계정·로컬 처리 기록은 암호화 저장하며 비밀값을 로그에 출력하지 않습니다. `operations.enc`의 확인 필요 기록을 임의로 지우면 중복 방지 근거를 잃으므로 삭제하지 않습니다.

검증 통과: 서버 계정 암호화·서명 API·무료 우선·상태 전환·기존 결제/주차/문자 등 67개 테스트. 서비스 5종 정상, 첫 서버 작업 Result=success/ExecMainStatus=0. 이 서버 전환 검증에서는 이미 완료된 실제 주문을 다시 등록하지 않았습니다.
